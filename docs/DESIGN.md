# Дизайн

Светлый минималистичный спортивный интерфейс, бело-красный. Референс в приложенных материалах не передавался — использованы палитра и компоновка из ТЗ.

## Палитра (`lib/core/theme.dart`)

| Назначение | Цвет |
|---|---|
| Фон | `#F5F5F5` |
| Карточки | `#FFFFFF` |
| Основной текст | `#151515` |
| Второстепенный | `#757575` |
| Акцент | `#F01428` |
| Предыдущие маршруты | `#EFA7AB` |
| Непройденные улицы | `#CCCCCC` |
| Разделители | `#E5E5E5` |
| Индикатор GPS | `#32B768` |

Слабый/поиск GPS — янтарный `#E6A100` (дополнительный статус-цвет, не из палитры ТЗ).

## Типографика

Системный шрифт Roboto (Material 3). Крупные цифры — `w800`, 22–44 sp (`BigStat`); подписи 12 sp `#757575`; заголовки экранов 26 sp `w800`.

## Компоненты

`AppCard` (белая карточка r=16), `BigStat` (подпись + крупное значение + единица), `GpsDot`, `SectionTitle`, `EmptyState`, `AppLogo`, `TrackThumbnail`, кнопки: `FilledButton` красная (высота ≥ 52, r=14), `OutlinedButton` с серой рамкой. Нижняя навигация: Старт · Моя карта · История · Статистика; настройки — иконка на «Старте».

## Карта

Полностью монохромная (`map_style.dart`): фон `#F5F5F5`, вода `#E2E2E2`, парки `#ECECEC`, здания `#E6E6E6`, дороги `#CCCCCC`/`#BEBEBE`, подписи серые. Красный — только маршруты и положение.

## Управление одной рукой

Основные кнопки — внизу экрана, высота ≥ 60 dp; блокировка случайных нажатий — долгое нажатие на замок.
