# Roadmap

География: Барнаул → Алтайский край → крупные города РФ → расширение покрытия России.

- **v0.1 (этот MVP)** — офлайн-карта, запись, история, накопительная карта GPS-линий, статистика, GPX, бэкап.
- **v0.2** — исследование улиц: Map Matching, уникальные километры, районы, достижения.
- **v0.3** — облачная синхронизация, сервер и хранилища в РФ, аккаунты, согласия по 152-ФЗ.
- **v0.4** — веб-версия (общая карта, история, статистика, планирование, импорт/экспорт GPX). Фоновая запись остаётся за мобильным приложением.
- **v0.5** — редактор GPS Art и планирование маршрутов.
- **v1.0** — публичный релиз.

Технический долг из v0.1: подложка карты в изображении маршрута, объединение тайлов соседних карт, иконка/POI-спрайты, проверка на Samsung/агрессивной экономии энергии, динамический аудит трафика.

- **v0.3** — карта Яндекс MapKit (онлайн), без офлайн-карт.
