# Инфраструктура

## Сетевые обращения готового приложения

| Что | Куда | Когда |
|---|---|---|
| Тайлы и данные карты | сервисы Яндекс MapKit (через SDK) | при показе карты |
| Проверка связи | DNS-запрос `yandex.ru` | раз в 20 с, пока открыта карта |

Больше никаких сетевых запросов нет: ни собственной аналитики и телеметрии, ни Firebase/Google Maps/Mapbox/Supabase.
`allowBackup=false` — без облачного автобэкапа Android. Что именно передаёт сам MapKit SDK Яндексу, определяется его лицензией и политикой Яндекса; независимой проверки трафика не проводилось.

Проверки: `tool/audit_network.sh` (запрещённые зависимости, список URL в коде) — статический.

## Координаты и история

Хранятся только локально (SQLite на устройстве). Наружу уходят лишь при действиях пользователя (экспорт GPX/картинки/копии через системное «Поделиться»).

## Инструменты сборки (только разработка)

GitHub Actions, pub.dev, Maven (MapKit SDK) — на этапе сборки.
