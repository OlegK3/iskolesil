# Инфраструктура

## Сетевые обращения готового приложения

| Что | Куда | Когда |
|---|---|---|
| Тайлы, стиль, глифы | `http://127.0.0.1:<порт>` (внутри устройства) | всегда |
| Каталог карт | `CATALOG_URL` (`--dart-define`), **по умолчанию пусто** | только если задан и пользователь открыл «Карты городов» |
| Файл карты | `url` из каталога (только HTTPS) | только по нажатию «Скачать/Обновить» |

Больше никаких сетевых запросов нет: ни аналитики, ни телеметрии, ни Firebase/Google Maps/Mapbox/Supabase Cloud, ни зарубежных CDN. Разрешение `INTERNET` нужно для loopback-сервера и загрузки карт. `allowBackup=false` — без облачного автобэкапа Android. Cleartext HTTP разрешён только для `127.0.0.1`/`localhost`.

Проверки: `tool/audit_network.sh` (запрещённые зависимости, список URL в коде) — статический. **Динамический аудит трафика на устройстве не проводился.**

## Координаты и история

Хранятся только локально (SQLite на устройстве). Наружу уходят лишь при действиях пользователя (экспорт GPX/картинки/копии через системное «Поделиться»). В MVP нет аккаунтов, поэтому 152-ФЗ в части сбора ПДн оператором не задействован; при появлении серверной части (v0.3) потребуются: согласие, политика, удаление/экспорт данных, хранение в РФ.

## Инструменты сборки (только разработка)

GitHub Actions, Planetiler, Geofabrik, openmaptiles/fonts, pub.dev — используются **на этапе сборки**, готовое приложение от них не зависит.

## Размещение карт в РФ (после MVP)

- Достаточно S3-совместимого/статического хранилища с HTTPS: Selectel, Timeweb Cloud, Yandex Cloud, VK Cloud (фактический регион размещения проверять при заказе).
- Разместить `<id>.mbtiles` и `catalog.json`; записи каталога готовит `tool/build_catalog_entry.py <файл> <id> <имя> <bounds> <версия> --url https://…` (считает размер и SHA-256).
- Приложение собрать с `--dart-define=CATALOG_URL=https://…/catalog.json`.
- Платный хостинг не выбран и не требуется для MVP.

## Будущий сервер (v0.3+)

PostgreSQL/PostGIS, собственный backend (REST) или self-hosted Supabase, Nginx, Docker Compose, S3-совместимое хранилище; всё на российском VPS. Архитектура переносима: никаких привязок к провайдеру.

## Масштабирование покрытия

Один `.mbtiles` на город/регион; тайлы z0–14 (overzoom выше). Для крупных регионов — несколько файлов; объединение векторных тайлов на стыках в v0.1 не делается (см. README).
