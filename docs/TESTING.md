# Тестирование

## Автоматические (в CI) — **не запускались**

`flutter test`: геометрия, фильтры трека (точность, скачки, дрейф, разрыв, пауза), набор высоты, статистика (взвешенная средняя скорость), GPX (экспорт→импорт, сегменты, null-значения, ошибки). Результаты появятся в логе GitHub Actions.

## Ручная проверка на устройстве — **не проводилась ни одна**

| Проверка | Статус |
|---|---|
| APK устанавливается и запускается | не проверено |
| Карта Барнаула без сети (после установки из файла) | не проверено |
| Запись с выключенным экраном/свёрнутым приложением | не проверено |
| Расчёт времени и расстояния на реальной поездке | не проверено |
| Пауза / завершение | не проверено |
| Потеря GPS, выезд за карту | не проверено |
| Авиарежим с включённой геолокацией | не проверено |
| Аварийное закрытие → восстановление | не проверено |
| Отзыв разрешения во время поездки | не проверено |
| Повреждённая загрузка карты / недостаток места / обновление карты | не проверено |
| Samsung и другие агрессивные режимы энергосбережения | не проверено |
| Импорт/экспорт GPX (в другие приложения) | не проверено |
| Резервная копия → восстановление | не проверено |
| Динамический аудит сетевых запросов (mitm/tcpdump) | не проверено |

Рекомендация для Samsung/Xiaomi и т.п.: отключить оптимизацию батареи для приложения, иначе ОС может остановить запись.
