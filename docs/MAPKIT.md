# Яндекс MapKit

Пакет: `yandex_mapkit` ^4.3.0 (Flutter-обёртка, использует MapKit SDK 4.39.1, вариант **lite**).
Карта используется только для показа; запись поездки (GPS, база данных) от неё не зависит.

## Ключ API
- Секрет репозитория `YANDEX_MAPKIT_API_KEY` передаётся в шаг `bash tool/bootstrap.sh` через `env`.
- `tool/patch_android.py` создаёт в временном (не коммитимом) каталоге `android/` класс `MainApplication.kt`
  с вызовом `MapKitFactory.setApiKey(...)`. В исходниках репозитория ключа нет, в логи он не выводится.
- Если секрета нет, сборка останавливается с понятным сообщением.
- Локально: файл `mapkit.properties` в корне (`YANDEX_MAPKIT_API_KEY=...`), он в `.gitignore`.
- Ключ мобильного SDK лежит внутри APK и может быть извлечён. Проверьте в кабинете разработчика Яндекса, какие
  ограничения использования ключа доступны для вашего типа лицензии (в документации SDK мы их не нашли).

## Лицензия и лимит
- Суточный лимит в кабинете (1000) — по документации Яндекса это число **уникальных пользователей в сутки (DAU)**,
  а не число запросов; перемещение карты отдельным платным запросом не считается. При превышении нужна платная лицензия.
- Подтверждение поддержки Яндекса о записи собственных велопоездок храните у себя.
- Логотип и атрибуцию Яндекса приложение не скрывает и не перекрывает: карта на экранах с нижними панелями
  расположена над панелью.

## Стиль
`_monoStyle` в `lib/ui/widgets/track_map.dart` — штатные JSON-стили MapKit (`setMapStyle`): светло-серый фон,
серые здания/парки/вода, белые дороги, тёмно-серые подписи, скрыты коммерческие POI.
Если стиль не применился, остаётся стандартная карта.

## Связь
Раз в 20 секунд проверяется DNS-запись `yandex.ru`; при потере связи один раз показывается сообщение. На запись не влияет.
