# Подпись APK

Чтобы новые версии устанавливались поверх старых, APK всегда должен быть подписан одним и тем же ключом.

1. Создайте в репозитории 4 секрета (Settings → Secrets and variables → Actions):
   `ANDROID_KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
2. Workflow `build-apk.yml` сам декодирует ключ и подпишет релиз.
3. Без секретов APK подписывается временным debug-ключом (в логе будет предупреждение).

Ключ и пароль храните отдельно от репозитория. Потеря ключа = невозможность обновления поверх.

Версия v0.1 была подписана временным ключом, поэтому переход на v0.2 требует **одной** переустановки:
сделайте резервную копию в приложении v0.1 (Настройки), сохраните `barnaul.mbtiles`, удалите v0.1,
установите v0.2, восстановите копию. Дальше обновления ставятся поверх.
