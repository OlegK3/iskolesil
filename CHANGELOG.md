# Изменения

## 0.3.0 (versionCode 3)
- Карта заменена на Яндекс MapKit (онлайн) на всех экранах; офлайн-карты, каталог городов, сервер MBTiles и MapLibre удалены.
- Ключ MapKit передаётся из секрета `YANDEX_MAPKIT_API_KEY`; в коде и логах его нет.
- Монохромный стиль карты штатными средствами SDK.
- Главный экран без привязки к городу; новые поездки без названия города.
- minSdk 26.

## 0.2.0 (versionCode 2)
- Новая главная: шапка, городское фото, «Начать поездку», карточки Моя карта / Статистика / История, город и «О приложении».
- Экран «Куда поедем?» перед поездкой (маршрутизация отложена, см. docs/ROUTING.md).
- Кнопка «Где я» на подготовке к поездке, активной поездке и «Моей карте».
- Убрана блокировка экрана; запись в фоне работает как раньше.
- Карта поездки в истории: масштабирование, возврат к исходному виду, полноэкранный просмотр.
- Страница «О приложении».
- Демо-режим удалён полностью (данные пользователя не затрагиваются).
- Новая иконка (адаптивная, монохромная), версия поднята.
- Подпись релиза постоянным ключом через GitHub Secrets.
