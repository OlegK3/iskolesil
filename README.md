# ИСКОЛЕСИЛ — «У каждой улицы — твоя история»

Офлайн GPS-трекер для велосипедистов: накопительная карта всех поездок, история, статистика, GPX, GPS Art.
MVP v0.1, Android, первый город — Барнаул. Flutter/Dart, Riverpod, SQLite, MapLibre, данные OpenStreetMap.

> **Статус честно.** Весь код написан без возможности компиляции и запуска (в среде разработки не было Flutter SDK, Android SDK и доступа к pub.dev). **Ни одна сборка и ни один тест ещё не запускались.** Первая сборка в GitHub Actions, вероятно, потребует пары правок по логу ошибок. См. [docs/TESTING.md](docs/TESTING.md) и «Известные ограничения».

## Быстрый старт: сборка APK на GitHub

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки (ветка `main`).
2. Вкладка **Actions → Build APK** запустится сама (или Run workflow). Она создаёт Android-проект (`tool/bootstrap.sh`), генерирует глифы шрифтов, делает `flutter analyze`, `flutter test`, `flutter build apk --release`.
3. Скачайте артефакт `iskolesil-apk` → `app-release.apk`, установите на телефон (разрешите установку из неизвестных источников). APK подписан debug-ключом — для личной установки достаточно, для публикации нужен свой ключ.
4. Если сборка упала — откройте лог шага, который упал, и пришлите его мне: поправлю.

### Карта Барнаула (настоящая, офлайн)

1. **Actions → Build city map (MBTiles) → Run workflow** (значения по умолчанию — Барнаул и пригороды). Нужно 30–90 минут: Planetiler скачивает выгрузку OSM Сибирского ФО с Geofabrik и строит векторные тайлы OpenMapTiles.
2. Скачайте артефакт `city-map-barnaul` → `barnaul.mbtiles`, перенесите на телефон.
3. В приложении: **Настройки → Карты городов → Установить из файла**. Файл проверяется и только потом устанавливается. Размер заранее неизвестен — проверьте после сборки (ориентир десятки МБ, но это не подтверждено).

Другие города: `tool/build_city_map.sh <id> "<Название>" <minLon,minLat,maxLon,maxLat> <URL .osm.pbf>`. Подробно: [docs/MAPS.md](docs/MAPS.md).

### Локальная сборка

Нужны Flutter stable, Java 21, Android SDK. `bash tool/bootstrap.sh && bash tool/make_glyphs.sh && flutter pub get && flutter run`.

## Что реализовано (по ТЗ)

Старт · активная поездка (карта, показатели, пауза/продолжение/завершение с подтверждением, GPS-индикатор) · завершение/детали (редактирование, удаление, экспорт GPX, изображение маршрута со скрытием начала/конца) · «Моя карта» (все треки, выбор, фильтр дат, скрытие треков) · история (сортировка) · статистика (неделя/месяц/год/всё, график) · настройки (разрешения, единицы, импорт/экспорт GPX, резервная копия/восстановление, удаление данных, атрибуция) · «Карты городов» (каталог, установка из файла, загрузка с докачкой и SHA-256, удаление, место, Wi-Fi only) · локальный сервер тайлов MBTiles · фоновая запись через Foreground Service (geolocator) с записью каждой точки в БД · восстановление после сбоя.

## Известные ограничения

- Не собиралось и не тестировалось (см. выше). Совместимость версий пакетов (особенно `maplibre_gl`) и API не проверена.
- Изображение маршрута рисуется на светлой сетке **без векторной подложки карты** (отрисовка тайлов вне MapLibre в v0.1 не реализована).
- Каталог карт: сервер в РФ не развёрнут, URL и контрольные суммы не выдуманы; загрузка по сети реализована, но не проверена на реальном источнике. Работает установка из файла.
- Несколько городов: на малых масштабах (z ≤ ~8) тайл берётся из одной карты (по центру тайла), данные соседних городов в одном тайле не объединяются.
- Во время паузы GPS-поток остаётся включённым (сохраняет службу живой; расходует батарею).
- Если ОС принудительно убила процесс, запись остановится; точки до этого момента сохранены, при следующем запуске предлагается продолжить/завершить.
- Нет иконки приложения (стандартная Flutter), нет спрайтов/POI на карте.
- Резервная копия содержит поездки и точки, но не настройки и не карты.
- Нет Map Matching и «процента исследованных улиц» — по ТЗ.
- Проверка Samsung и других агрессивных режимов энергосбережения не проводилась.
